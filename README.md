
# Portfólio Acadêmico - Fundamentos da Programação Web

Portfólio pessoal desenvolvido como Atividade Prática para o curso de Análise e Desenvolvimento de Sistemas (UNINTER). 

O objetivo do projeto foi construir uma aplicação web responsiva e funcional.

##  Linguagens Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Estilização com uso de variáveis , estruturação principal baseada em CSS Grid e alinhamentos internos via Flexbox. Media Queries aplicadas para responsividade mobile.
* **JavaScript:** Manipulação de DOM para interatividade (Menu Mobile e Tema Escuro) e validação lógica de formulários.

##  Funcionalidades Implementadas

-  **Navegação Single Page (Anchor Navigation):** Menu fixo com rolagem suave para as seções do site.
-  **Responsividade:** Layout adaptável para dispositivos móveis.
-  **Menu Dinâmico:** Botão em barras para exibição do menu em telas menores.
-  **Modo Claro/Escuro:** Alternância de tema gerenciada via JavaScript com troca de classes no CSS.
-  **Validação de Formulário:** Verificação de campos em branco e validação de formato de e-mail antes da simulação de envio.
